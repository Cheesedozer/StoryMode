Help

Working with blueprints

  • Library: the same library as Story Mode in SillyTavern. Click a card to open it.
  • Save to Library (Ctrl+S): writes your changes; the SillyTavern tab picks them up automatically.
  • Generate AI: runs blueprint generation in your open SillyTavern tab, using your Story Mode connection profiles.
  • Import / Export PNG: blueprint PNGs are interchangeable with the extension's.

Keyboard shortcuts

  • Ctrl+S save · Ctrl+N new blueprint · Ctrl+O import PNG
  • Alt+D details · Alt+E scenes · Alt+S characters · Alt+C cover
